## Summary

This lab successfully demonstrated the detection of unauthorized user creation and privilege escalation activities using Wazuh SIEM.

---

## Key Takeaways

- User account creation should always be monitored as it may indicate unauthorized access or persistence.
- Privilege escalation events provide critical evidence of an attacker attempting to gain elevated permissions.
- Wazuh can detect user management and privilege changes by monitoring authentication and audit logs.
- Correlating user creation with privilege escalation helps identify potential persistence mechanisms.
